# PS5 etaHEN Cheats

MC4 trainers for jailbroken PS5 (etaHEN / CheatRunner).

## How to use

1. Extract the `.rar` and put the `.mc4` file into `/data/etaHEN/cheats/mc4` (or CheatRunner: `/data/cheatrunner/cheats/mc4`).
2. On the PS5: **Cheats → Cache And Reload Cheats List**.
