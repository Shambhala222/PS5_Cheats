# PS5 Cheats

MC4 trainers for jailbroken PS5 (CheatRunner). Also works with etaHEN.

## How to use

1. Put the `.mc4` into `/data/etaHEN/cheats/mc4` or `/data/cheatrunner/cheats/mc4`.
2. On the PS5: **Cheats → Cache And Reload Cheats List**.
